# Rand zkVM M4.3 — EVM interpreter guest (ERC-20 subset) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An EVM interpreter compiled to RV32IM runs as a guest of `rand_zkvm`, executes a Solidity ERC-20's `transfer`, `balanceOf` and `approve` with the contract's storage as Merkle witnesses, and proves it under `R_exec` — M4.3's exit test: an ERC-20 `transfer` proves and verifies, and the state-root transition is bound by the public output.

**Architecture:** The interpreter is a `no_std` library crate, `evm-core`, that is generic over a `Host` trait for the two things a guest cannot compute itself (Keccak-f[1600], the Poseidon2 sponge). On the host the trait is implemented with the research crate's own reference functions, so every opcode, the 256-bit arithmetic and the storage tree are unit-tested natively and differentially against `revm`; on the target the same code is a thin `guest-sdk` binary whose `Host` is the two syscalls. Contract storage is a depth-32 sparse Merkle tree over 256-bit slots hashed with the domain-tagged Poseidon2 sponge the note layer already uses, so `SLOAD`/`SSTORE` are the note tree's `MERKLE_VERIFY` in Rust rather than a Keccak walk. Nothing in the machine changes: no new table, no new syscall, no new public value; the guest is one more compiled binary and one more `hc`.

**Tech Stack:** Rust 1.98.1, `riscv32im-unknown-none-elf` + `llvm-tools` (installed), `guest-sdk` (M4.1/M4.2), Plonky3 0.7 (unchanged), dev-dependencies on the host only: `revm` (differential oracle), `num-bigint 0.4` (256-bit arithmetic oracle), `hex 0.4`. `solc` is not on the build machines: the contract's runtime bytecode is compiled once with a pinned static `solc` and committed as a hex file (Task 5), so no task's tests need it.

**Spec:** `docs/superpowers/specs/2026-09-11-zkvm-m4-design.md` §4 (M4.3), §6 (what does not change), §7 (rulings), §8 (open items). Background: `research/docs/04-guests.md` (the EVM path), `research/docs/01-isa.md` (syscalls), `research/docs/03-privacy.md` (`H_IN`, public values), `docs/superpowers/plans/2026-09-12-zkvm-m4-2.md` Task 5 (how a compiled guest is built and committed).

## Global Constraints

- Every cargo command: `cargo +1.98.1 ...` run from `research/` unless a task says otherwise; guest crates are their own workspace roots (as `guests-compiled/keccak256` is) so a plain `cargo test` from `research/` never needs the RISC-V target.
- **The machine is unchanged** (spec §6): no table, bus, syscall, public value or `Proof` field changes; `tests/tables.rs::alu_max_constraint_degree_is_pinned` and every shape test stay as they are. M4.3 is a *guest* milestone. It is still a constraint-set change for the fullnode only in the sense that a new `hc` is registered; the fullnode is **not** re-vendored by this plan.
- **Scope of the EVM** (spec §4): stack, memory, calldata, `SLOAD`/`SSTORE`, arithmetic including 256-bit `MUL`/`DIV`/`SDIV`/`MOD`/`SMOD`/`ADDMOD`/`MULMOD`/`EXP`/`SIGNEXTEND` (software over eight 32-bit limbs, RV32M), comparison, bitwise, `SHL`/`SHR`/`SAR`/`BYTE`, `KECCAK256` (M4.2), `ADDRESS`, `CALLER`, `CALLVALUE`, `CALLDATALOAD`/`CALLDATASIZE`/`CALLDATACOPY`, `CODESIZE`/`CODECOPY`, `RETURNDATASIZE` (always 0), `POP`/`MLOAD`/`MSTORE`/`MSTORE8`/`MSIZE`/`PC`/`GAS`/`JUMP`/`JUMPI`/`JUMPDEST`, `PUSH0`–`PUSH32`, `DUP1`–`DUP16`, `SWAP1`–`SWAP16`, `LOG0`–`LOG4` (topics hashed into the output, data dropped), `RETURN`, `REVERT`, `STOP`, `INVALID`. Out of scope, and every one of them **traps**: the `CALL`/`CREATE` family, precompiles, `SELFDESTRUCT`, `BLOCKHASH`, `TIMESTAMP`/`NUMBER`/`COINBASE`/`DIFFICULTY`/`GASLIMIT`/`CHAINID`/`BASEFEE`/`SELFBALANCE`/`BALANCE`/`ORIGIN`/`GASPRICE`/`EXTCODE*`/`RETURNDATACOPY` with a non-zero length, `TLOAD`/`TSTORE`, `MCOPY`, `BLOBHASH`. A trap is an exceptional halt (status word 2, below).
- **Gas** is a counter with the Shanghai static schedule for the supported subset and no refunds: `zero` 0, `base` 2, `verylow` 3, `low` 5, `mid` 8, `high` 10, `EXP` 10 + 50 per non-zero byte of the exponent, `KECCAK256` 30 + 6 per word, `SLOAD` 2100 (cold; no access-list warmth is tracked), `SSTORE` 20000 when the pre-value is zero and the new value is not, 2900 otherwise, `LOGn` 375 + 375·n + 8 per data byte, `JUMPDEST` 1, memory expansion `3·w + ⌊w²/512⌋` for `w` words, `CALLDATACOPY`/`CODECOPY` 3 + 3 per word copied. Running out of gas is an exceptional halt.
- **Status word** (`out0`): `1` success (`STOP`/`RETURN`), `0` revert (`REVERT`), `2` exceptional halt (out of gas, stack underflow/overflow (1024), bad jump, `INVALID`, a trapping opcode, a return-data or memory offset above `MAX_MEMORY_BYTES`). Both `0` and `2` bind `post_root = pre_root` and an empty log set; `0` binds the revert data as the return data, `2` binds empty return data.
- **Public output** (plan ruling, see the table below): `out0 = status`; `out1..out7` = words `0..6` of `hash(domain::EVM_OUT, [codehash(8) ‖ pre_root(8) ‖ post_root(8) ‖ return_hash(8) ‖ logs_hash(8)])` — 40 words through the domain-tagged sponge (`notes::hash`), a 224-bit binding of the contract, both roots, the return data and the logs. `codehash = keccak256(runtime bytecode)`, `return_hash = keccak256(return data)`, `logs_hash = keccak256(be32(n_logs) ‖ for each log in order: be32(n_topics) ‖ topics…)` (data dropped), each 32-byte hash as 8 little-endian words in byte order (`word[i] = LE(bytes[4i..4i+4])`, the same packing `guest_sdk::keccak256`'s test guest uses).
- **Storage tree** (spec §4 plus the rulings below): binary Merkle tree of depth `notes::DEPTH = 32` over 256-bit slots; leaf position = the **top 32 bits, big-endian,** of `keccak256(slot as 32 big-endian bytes)` read as a `u32` index whose bit `i` (LSB first) chooses left/right at level `i`, the same index convention as `emit_merkle_verify`; leaf hash = `hash(domain::STORAGE_LEAF, [slot(8) ‖ value(8)])`; node hash = `hash(domain::NODE, [left(8) ‖ right(8)])` exactly as the note tree; an absent slot's leaf is `hash(domain::STORAGE_LEAF, [0; 16])` (value zero), so the empty tree has a well-defined root `EMPTY_ROOT[32]`. Every slot the run touches has a witness (value + 32 siblings against the pre-state root); a slot without a witness that the bytecode touches is an exceptional halt. `MAX_WITNESSES = 16`.
- **Input vector layout** (`READ_INPUT` word indices, all lengths in bytes, byte strings packed 4 per word little-endian, zero-padded): `[n_code, code…, n_calldata, calldata…, address(8), caller(8), callvalue(8), gas_limit(1), pre_root(8), n_witnesses(1), witness…]` with each witness `[slot(8), value(8), sibling_0(8), …, sibling_31(8)]` (273 words). 256-bit EVM values are 8 words, **little-endian limb order** (`limb[0]` = least significant 32 bits) — the `u256` type's own representation, so no byte-swapping on the way in; addresses are the 20-byte value right-aligned in a 256-bit word as the EVM does.
- **Limits**: `MAX_CODE_BYTES = 24_576` (EIP-170), `MAX_CALLDATA_BYTES = 4_096`, `MAX_MEMORY_BYTES = 65_536` (guest RAM is 1 MiB with a 64 KiB stack, `guest-sdk/guest.ld`; the interpreter's stack is 1024 × 32 bytes = 32 KiB; memory 64 KiB; code 24 KiB; all static arrays in `.bss`), `MAX_RETURN_BYTES = 1_024`, `MAX_LOGS = 8`, `MAX_TOPICS = 4`.
- **Tier**: the exit test's `transfer` must prove at **tier 16 or lower**; the spec's estimate is tier 14. Task 5 measures and records the tier, cycles, permutations and proof size; if it lands above 14 the report names the dominant cost (dispatch, `u256`, program digest rows, storage hashes) so the follow-up is targeted — this plan does not optimise past correctness.
- **Proof size** at the production profile with the keccak table present is about 1.25 MB + 1.91 MB ≈ 3.2 MB (M4.2's measurement); the fullnode's `MAX_PROOF_BYTES` (2 MiB from constraint set 5) does not admit it. That is a fullnode-side change for the vendoring that carries M4.3 (a 4 MiB proof cap, block cap revisited per `fullnode/docs/block-space.md`), noted in Task 5's docs, not made here.
- Commit style as M4.2: `research: evm — …`, `research: docs — …`; tests first; every task ends green with `cargo +1.98.1 test` on the touched suites.

## Rulings made in this plan

| ruling | why | cost if wrong |
|---|---|---|
| `evm-core` is a `no_std` library generic over a `Host` trait, tested natively and compiled into the guest | an interpreter cannot be debugged through proofs; native tests plus a differential oracle (`revm`) are the only way to get 100+ opcodes right; the guest binary is then a 40-line wrapper | two build targets for one crate; the target build is checked by the committed `.bin` |
| the public output is `status` plus a 224-bit domain-tagged digest of `(codehash, pre_root, post_root, return_hash, logs_hash)`, not the spec's "96 bits of the post-root in `out1..3`" | 96 bits of a state root is 2^48 collision work, below the proof's own ~86-bit floor; a chain verifying the call knows `codehash`, `pre_root`, the claimed `post_root` and the return data and recomputes the digest, so nothing is lost and the pre-state root is bound too (the spec had no binding of the pre-root at all, `H_IN` being hiding) | the output layout is one function in one place (`abi.rs`); if the user prefers the spec's split, `out1..7` is re-cut there |
| slot index = top 32 bits of `keccak256(slot)` | the spec says "keccak256(slot) prefix bits, depth 32"; the choice of *which* 32 is a convention, pinned here so host and guest agree | none if consistent |
| leaf = `hash(STORAGE_LEAF, slot ‖ value)`, new domain tags `STORAGE_LEAF = 12`, `EVM_OUT = 13` in `notes::domain` | one domain per fixed message length is the note layer's rule (`AGENTS.md`); the storage leaf (16 words) and the output digest (40 words) are new lengths | two constants in a vendored file; the fullnode's `tests/shielded.rs` domain assertions are unaffected |
| multi-slot updates refresh other witnesses' siblings level by level | independent witnesses against the pre-root go stale as soon as one leaf changes; the standard fix is to overwrite the sibling any other witness holds at the level where its path diverges from the updated one | O(witnesses × depth) copies, 16 × 32 at most |
| status `2` for every exceptional halt, `0` only for `REVERT` | a chain must distinguish "the contract said no" (revert data is meaningful) from "the run was invalid"; both revert state | one extra status value |
| the contract is a self-contained `ERC20.sol` in the repo with OpenZeppelin v4's storage layout (`_balances` slot 0, `_allowances` slot 1, `_totalSupply` slot 2), compiled once with a pinned static `solc`, runtime bytecode committed | the spec asks for an OpenZeppelin-style ERC-20 compiled once; vendoring OpenZeppelin's sources for one file is dead weight, and the storage layout is what the tests need to know | if the user wants OZ's exact bytecode, Task 5's `contracts/` gets the OZ file instead and the slots stay the same |
| gas is metered with cold costs only, no access lists, no refunds | spec §4: "gas accounting as a counter (no refunds)"; warm/cold tracking is a per-transaction set the exit test never exercises | gas figures differ from mainnet's; nothing on-chain depends on them yet |
| `revm` is the differential oracle for opcode semantics, `num-bigint` for `u256` | hand-written expectations for 256-bit `SDIV`/`SMOD`/`SAR`/`SIGNEXTEND` edge cases are exactly where interpreters go wrong; an oracle finds them | two dev-dependencies, host only |

```rust
// evm-core/src/lib.rs
#![no_std]
pub mod u256; pub mod storage; pub mod interp; pub mod abi;
/// The two things a guest cannot compute itself. Both operate in place on 32-bit words.
pub trait Host {
    /// One Keccak-f[1600] permutation of the 50-word state (lane i: low word 2i, high word 2i+1).
    fn keccak_f(&mut self, state: &mut [u32; 50]);
    /// The Poseidon2 sponge over `words[..n]`, digest written to `words[..8]` (POSEIDON2 syscall semantics).
    fn poseidon2(&mut self, words: &mut [u32], n: usize);
}
/// keccak256 over the host's permutation: rate 136, pad 0x01…0x80, little-endian lanes — byte-identical to guest_sdk::keccak256 and research's keccak::keccak256.
pub fn keccak256<H: Host>(h: &mut H, msg: &[u8]) -> [u8; 32];
/// hash(domain, msg) = poseidon2([domain, msg…]) — byte-identical to research's notes::hash.
pub fn dhash<H: Host>(h: &mut H, domain: u32, msg: &[u32]) -> [u32; 8];

// evm-core/src/u256.rs
#[derive(Clone, Copy, PartialEq, Eq, Default, Debug)]
pub struct U256(pub [u32; 8]);           // limb 0 = least significant
impl U256 {
    pub const ZERO: U256; pub const ONE: U256; pub const MAX: U256;
    pub fn from_u32(v: u32) -> U256; pub fn from_u64(v: u64) -> U256;
    pub fn from_be_bytes(b: &[u8; 32]) -> U256; pub fn to_be_bytes(&self) -> [u8; 32];
    pub fn from_be_slice(b: &[u8]) -> U256;    // ≤ 32 bytes, right-aligned (PUSHn, CALLDATALOAD tail)
    pub fn is_zero(&self) -> bool; pub fn low_u32(&self) -> u32; pub fn low_u64(&self) -> u64;
    pub fn fits_u32(&self) -> bool;             // limbs 1..8 all zero
    pub fn bit_len(&self) -> u32; pub fn byte_len(&self) -> u32;
    pub fn add(&self, o: &U256) -> U256; pub fn sub(&self, o: &U256) -> U256; pub fn mul(&self, o: &U256) -> U256;   // wrapping mod 2^256
    pub fn div(&self, o: &U256) -> U256; pub fn rem(&self, o: &U256) -> U256;   // x/0 = 0, x%0 = 0 (EVM)
    pub fn sdiv(&self, o: &U256) -> U256; pub fn smod(&self, o: &U256) -> U256; // two's complement; MIN/-1 = MIN
    pub fn addmod(&self, o: &U256, m: &U256) -> U256; pub fn mulmod(&self, o: &U256, m: &U256) -> U256; // 512-bit intermediate, m = 0 → 0
    pub fn exp(&self, e: &U256) -> U256; pub fn signextend(&self, b: &U256) -> U256;
    pub fn lt(&self, o: &U256) -> bool; pub fn slt(&self, o: &U256) -> bool; pub fn is_neg(&self) -> bool;
    pub fn and(&self, o: &U256) -> U256; pub fn or(&self, o: &U256) -> U256; pub fn xor(&self, o: &U256) -> U256; pub fn not(&self) -> U256;
    pub fn shl(&self, n: &U256) -> U256; pub fn shr(&self, n: &U256) -> U256; pub fn sar(&self, n: &U256) -> U256; // n ≥ 256 → 0 / 0 / sign fill
    pub fn byte(&self, i: &U256) -> U256;        // i-th byte from the most significant, i ≥ 32 → 0
}
```

`research/tests/evm_u256.rs`:

```rust
use evm_core::u256::U256;
use num_bigint::{BigInt, BigUint, Sign};
use rand::{Rng, SeedableRng};

fn big(u: &U256) -> BigUint { BigUint::from_bytes_be(&u.to_be_bytes()) }
fn from_big(b: &BigUint) -> U256 {
    let bytes = b.to_bytes_be(); let mut out = [0u8; 32];
    out[32 - bytes.len()..].copy_from_slice(&bytes); U256::from_be_bytes(&out)
}
fn signed(u: &U256) -> BigInt {
    let b = BigInt::from_biguint(Sign::Plus, big(u));
    if u.is_neg() { b - (BigInt::from(1u8) << 256) } else { b }
}
fn modulus() -> BigUint { BigUint::from(1u8) << 256 }
fn rnd(rng: &mut impl Rng) -> U256 {
    // mix full-width values with small ones and with values near 2^256 so every carry path is hit
    match rng.random_range(0..4) {
        0 => U256(core::array::from_fn(|_| rng.random())),
        1 => U256::from_u64(rng.random()),
        2 => U256::MAX.sub(&U256::from_u32(rng.random_range(0..3))),
        _ => { let mut l = [0u32; 8]; l[7] = rng.random(); l[0] = rng.random(); U256(l) }
    }
}

#[test]
fn arithmetic_matches_num_bigint_on_ten_thousand_random_pairs() {
    let mut rng = rand::rngs::StdRng::seed_from_u64(43);
    let m = modulus();
    for _ in 0..10_000 {
        let (a, b) = (rnd(&mut rng), rnd(&mut rng));
        let (ba, bb) = (big(&a), big(&b));
        assert_eq!(big(&a.add(&b)), (&ba + &bb) % &m);
        assert_eq!(big(&a.sub(&b)), (&ba + &m - &bb) % &m);
        assert_eq!(big(&a.mul(&b)), (&ba * &bb) % &m);
        if !b.is_zero() {
            assert_eq!(big(&a.div(&b)), &ba / &bb);
            assert_eq!(big(&a.rem(&b)), &ba % &bb);
        } else {
            assert_eq!(a.div(&b), U256::ZERO);
            assert_eq!(a.rem(&b), U256::ZERO);
        }
    }
}

#[test]
fn signed_division_and_modulo_follow_the_evm() {
    // EVM: SDIV truncates toward zero; SMOD takes the dividend's sign; MIN / -1 = MIN; x / 0 = 0.
    let mut rng = rand::rngs::StdRng::seed_from_u64(44);
    for _ in 0..10_000 {
        let (a, b) = (rnd(&mut rng), rnd(&mut rng));
        let (sa, sb) = (signed(&a), signed(&b));
        if sb.sign() == Sign::NoSign { assert_eq!(a.sdiv(&b), U256::ZERO); assert_eq!(a.smod(&b), U256::ZERO); continue; }
        let q = &sa / &sb; let r = &sa % &sb; // BigInt division truncates toward zero, remainder has the dividend's sign
        assert_eq!(signed(&a.sdiv(&b)), if q == (BigInt::from(1u8) << 255) { -(BigInt::from(1u8) << 255) } else { q });
        assert_eq!(signed(&a.smod(&b)), r);
    }
    let min = { let mut l = [0u32; 8]; l[7] = 0x8000_0000; U256(l) };
    assert_eq!(min.sdiv(&U256::MAX), min);
    assert_eq!(min.smod(&U256::MAX), U256::ZERO);
}

#[test]
fn modular_ops_use_a_wide_intermediate() {
    let mut rng = rand::rngs::StdRng::seed_from_u64(45);
    let m = modulus();
    for _ in 0..10_000 {
        let (a, b, n) = (rnd(&mut rng), rnd(&mut rng), rnd(&mut rng));
        let (ba, bb, bn) = (big(&a), big(&b), big(&n));
        if n.is_zero() { assert_eq!(a.addmod(&b, &n), U256::ZERO); assert_eq!(a.mulmod(&b, &n), U256::ZERO); continue; }
        assert_eq!(big(&a.addmod(&b, &n)), (&ba + &bb) % &bn);   // NOT (a + b mod 2^256) mod n
        assert_eq!(big(&a.mulmod(&b, &n)), (&ba * &bb) % &bn);
    }
    assert_eq!(big(&U256::MAX.addmod(&U256::MAX, &U256::from_u32(7))), (&m - 1u8 + &m - 1u8) % 7u8);
}

#[test]
fn exp_shifts_byte_and_signextend() {
    let mut rng = rand::rngs::StdRng::seed_from_u64(46);
    let m = modulus();
    for _ in 0..2_000 {
        let a = rnd(&mut rng);
        let e = U256::from_u32(rng.random_range(0..300));
        assert_eq!(big(&a.exp(&e)), big(&a).modpow(&big(&e), &m));
        let n = rng.random_range(0..300u32);
        let sh = U256::from_u32(n);
        assert_eq!(big(&a.shl(&sh)), if n >= 256 { BigUint::ZERO } else { (big(&a) << n) % &m });
        assert_eq!(big(&a.shr(&sh)), if n >= 256 { BigUint::ZERO } else { big(&a) >> n });
        let sar = signed(&a) >> n.min(255);
        assert_eq!(signed(&a.sar(&sh)), if n >= 256 { if a.is_neg() { BigInt::from(-1) } else { BigInt::ZERO } } else { sar });
    }
    // BYTE: index 0 is the most significant byte; index ≥ 32 is zero.
    let v = U256::from_be_bytes(&core::array::from_fn(|i| i as u8));
    assert_eq!(v.byte(&U256::from_u32(0)), U256::ZERO);
    assert_eq!(v.byte(&U256::from_u32(31)), U256::from_u32(31));
    assert_eq!(v.byte(&U256::from_u32(32)), U256::ZERO);
    assert_eq!(v.byte(&U256::MAX), U256::ZERO);
    // SIGNEXTEND b: sign-extend from byte b (0 = lowest byte); b ≥ 31 is the identity.
```

```rust
impl U256 {
    pub fn add(&self, o: &U256) -> U256 { let (r, _) = self.add_carry(o); r }
    fn add_carry(&self, o: &U256) -> (U256, u32) {
        let mut r = [0u32; 8]; let mut c = 0u64;
        for i in 0..8 { let s = self.0[i] as u64 + o.0[i] as u64 + c; r[i] = s as u32; c = s >> 32; }
        (U256(r), c as u32)
    }
    pub fn sub(&self, o: &U256) -> U256 {
        let mut r = [0u32; 8]; let mut b = 0i64;
        for i in 0..8 { let d = self.0[i] as i64 - o.0[i] as i64 - b; r[i] = d as u32; b = (d < 0) as i64; }
        U256(r)
    }
    /// Schoolbook 8×8 limbs, keeping only the low 8 (mod 2^256). RV32M's mul/mulhu do the 32×32→64.
    pub fn mul(&self, o: &U256) -> U256 { let w = mul_wide(&self.0, &o.0); U256(w[..8].try_into().unwrap()) }
    pub fn div(&self, o: &U256) -> U256 { if o.is_zero() { U256::ZERO } else { divrem(&self.0, &o.0).0 } }
    pub fn rem(&self, o: &U256) -> U256 { if o.is_zero() { U256::ZERO } else { divrem(&self.0, &o.0).1 } }
    pub fn is_neg(&self) -> bool { self.0[7] >> 31 == 1 }
    fn neg(&self) -> U256 { U256::ZERO.sub(self) }
    fn abs(&self) -> U256 { if self.is_neg() { self.neg() } else { *self } }
    pub fn sdiv(&self, o: &U256) -> U256 {
        if o.is_zero() { return U256::ZERO; }
        let q = self.abs().div(&o.abs());          // MIN.abs() = MIN (wraps) and MIN / 1 = MIN: the EVM's MIN / -1 = MIN falls out
        if self.is_neg() != o.is_neg() { q.neg() } else { q }
    }
    pub fn smod(&self, o: &U256) -> U256 {
        if o.is_zero() { return U256::ZERO; }
        let r = self.abs().rem(&o.abs());
        if self.is_neg() { r.neg() } else { r }
    }
    pub fn addmod(&self, o: &U256, m: &U256) -> U256 {
        if m.is_zero() { return U256::ZERO; }
        let (s, c) = self.add_carry(o);            // 257-bit sum: c is bit 256
        let mut wide = [0u32; 16]; wide[..8].copy_from_slice(&s.0); wide[8] = c;
        U256(rem_wide(&wide, &m.0))
    }
    pub fn mulmod(&self, o: &U256, m: &U256) -> U256 {
        if m.is_zero() { return U256::ZERO; }
        U256(rem_wide(&mul_wide(&self.0, &o.0), &m.0))
    }
    pub fn exp(&self, e: &U256) -> U256 {          // square-and-multiply over e's bits, MSB first
        let mut acc = U256::ONE; let mut base = *self; let bits = e.bit_len();
        for i in 0..bits { if (e.0[(i / 32) as usize] >> (i % 32)) & 1 == 1 { acc = acc.mul(&base); } base = base.mul(&base); }
        acc
    }
    pub fn signextend(&self, b: &U256) -> U256 {
        if !b.fits_u32() || b.low_u32() >= 31 { return *self; }
        let bit = b.low_u32() * 8 + 7;                   // the sign bit of byte b (byte 0 = least significant)
        let mask = U256::ONE.shl(&U256::from_u32(bit + 1)).sub(&U256::ONE);  // bits 0..=bit
        let set = (self.0[(bit / 32) as usize] >> (bit % 32)) & 1 == 1;
        if set { self.or(&mask.not()) } else { self.and(&mask) }
    }
    pub fn shl(&self, n: &U256) -> U256 {
        if !n.fits_u32() || n.low_u32() >= 256 { return U256::ZERO; }
        let (words, bits) = ((n.low_u32() / 32) as usize, n.low_u32() % 32); let mut r = [0u32; 8];
        for i in (words..8).rev() {
            let lo = self.0[i - words] << bits;
            let hi = if bits > 0 && i - words > 0 { self.0[i - words - 1] >> (32 - bits) } else { 0 };
            r[i] = lo | hi;
        }
        U256(r)
    }
    pub fn shr(&self, n: &U256) -> U256 { /* mirror of shl */ }
    pub fn sar(&self, n: &U256) -> U256 {
        let neg = self.is_neg();
        if !n.fits_u32() || n.low_u32() >= 256 { return if neg { U256::MAX } else { U256::ZERO }; }
        let r = self.shr(n);
        if !neg { return r; }
        let fill = U256::MAX.shl(&U256::from_u32(256 - n.low_u32()));   // the top n bits
        r.or(&fill)
    }
    pub fn byte(&self, i: &U256) -> U256 {
        if !i.fits_u32() || i.low_u32() >= 32 { return U256::ZERO; }
        U256::from_u32(self.to_be_bytes()[i.low_u32() as usize] as u32)
    }
```

```rust
impl StorageTree {
    fn find(&self, slot: &U256) -> Option<usize> { (0..self.n).find(|&i| self.witnesses[i].slot == *slot) }
    fn verify<H: Host>(&mut self, h: &mut H, i: usize) -> Result<(), StorageError> {
        if self.witnesses[i].verified { return Ok(()); }
        let w = &self.witnesses[i];
        let idx = slot_index(h, &w.slot);
        let mut cur = leaf_hash(h, &w.slot, &w.value);
        for l in 0..DEPTH {
            let sib = &self.witnesses[i].siblings[l];
            cur = if (idx >> l) & 1 == 0 { node_hash(h, &cur, sib) } else { node_hash(h, sib, &cur) };
        }
        if cur != self.root { return Err(StorageError::BadWitness); }
        self.witnesses[i].verified = true; Ok(())
    }
    pub fn load<H: Host>(&mut self, h: &mut H, slot: &U256) -> Result<U256, StorageError> {
        let i = self.find(slot).ok_or(StorageError::NoWitness)?; self.verify(h, i)?; Ok(self.witnesses[i].value)
    }
    pub fn store<H: Host>(&mut self, h: &mut H, slot: &U256, value: U256) -> Result<U256, StorageError> {
        let i = self.find(slot).ok_or(StorageError::NoWitness)?; self.verify(h, i)?;
        let prev = self.witnesses[i].value; self.witnesses[i].value = value;
        let idx = slot_index(h, slot);
        let mut cur = leaf_hash(h, slot, &value);
        for l in 0..DEPTH {
            // every other witness whose path agrees with ours above level l and differs at level l
            // has *our* node at level l as its sibling at level l: refresh it
            for j in 0..self.n {
                if j == i { continue; }
                let jdx = slot_index(h, &self.witnesses[j].slot);   // cache these per witness (a [u32; MAX_WITNESSES] filled at push) — 16 keccaks otherwise
                let same_above = (idx >> (l + 1)) == (jdx >> (l + 1)) || l == DEPTH - 1 && true;
                let differs_here = ((idx >> l) & 1) != ((jdx >> l) & 1);
                if same_above && differs_here { self.witnesses[j].siblings[l] = cur; }
            }
            let sib = self.witnesses[i].siblings[l];
            cur = if (idx >> l) & 1 == 0 { node_hash(h, &cur, &sib) } else { node_hash(h, &sib, &cur) };
        }
        self.root = cur; Ok(prev)
    }
}
```

(`same_above` at the top level `l = 31` is "the two indices agree on nothing above", i.e. always true; write it as `l == DEPTH - 1 || (idx >> (l + 1)) == (jdx >> (l + 1))`.) Cache each witness's index at `push` in an `indices: [u32; MAX_WITNESSES]` field so `store` does no Keccak per witness per level. Every other witness already verified stays verified: their paths' siblings were refreshed where the update touched them, and the root changed consistently, so a later `load` must **not** re-verify a refreshed witness against the new root — `verified` stays `true`. (The test's final loop pins this.)

```rust
fn run(code: &[u8], calldata: &[u8]) -> Outcome {
    let mut h = HostRef; let mut st = StorageTree::new(empty_root());
    Interpreter::new(&mut h, code, calldata, env(), &mut st).run()
}
fn run_with(code: &[u8], calldata: &[u8], tree: &SparseTree, slots: &[U256]) -> (Outcome, [u32; 8]) {
    let mut h = HostRef; let mut st = StorageTree::new(tree.root());
    for s in slots { let w = tree.witness(s); st.push(evm_core::storage::Witness { slot: w.slot, value: w.value, siblings: w.siblings, verified: false }).unwrap(); }
    let o = Interpreter::new(&mut h, code, calldata, env(), &mut st).run(); (o, st.root)
}
fn ret_u256(o: &Outcome) -> U256 { assert_eq!(o.ret_len, 32); U256::from_be_slice(&o.ret[..32]) }
/// PUSHn helper: the smallest push that holds `v`.
fn push(v: u64) -> Vec<u8> { let b = v.to_be_bytes(); let s = b.iter().position(|&x| x != 0).unwrap_or(7); let mut out = vec![0x60 + (7 - s) as u8]; out.extend_from_slice(&b[s..]); out }
```

Structure:

```rust
pub struct Interpreter<'a, H: Host> {
    h: &'a mut H, code: &'a [u8], calldata: &'a [u8], env: Env, storage: &'a mut StorageTree,
    stack: [U256; STACK_LIMIT], sp: usize,
    memory: [u8; MAX_MEMORY_BYTES], msize: usize,          // msize: highest touched byte rounded up to 32
    jumpdests: [u32; MAX_CODE_BYTES / 32],                  // bitmap: bit i set iff code[i] is a JUMPDEST not inside push data
    pc: usize, gas: u64,
    ret: [u8; MAX_RETURN_BYTES], ret_len: usize, logs: [Log; MAX_LOGS], n_logs: usize,
}
```

`new` scans the code once for the bitmap (advance by `1 + n` over `PUSHn`). `run` is a `loop` over `self.code.get(self.pc)` (past the end = `Stop`) with a `match op` on the byte; every arm first charges gas (`self.gas = self.gas.checked_sub(cost).ok_or(Halt::OutOfGas)?` — write the body as `fn step(&mut self) -> Result<Option<Halt>, Halt>` and let `?` carry the halt), then pops/pushes with `pop()?`/`push(v)?` returning `StackUnderflow`/`StackOverflow`. Memory access goes through `fn mem(&mut self, offset: &U256, len: usize) -> Result<usize /*start*/, Halt>` which rejects offsets not fitting `u32` or `offset + len > MAX_MEMORY_BYTES` with `OutOfBounds`, charges expansion (`cost(w_new) - cost(w_old)` with `cost(w) = 3w + w*w/512`), and bumps `msize`. `KECCAK256` copies the memory range into a `[u8; MAX_MEMORY_BYTES]`-free path: hash directly from `&self.memory[start..start+len]` with `evm_core::keccak256(self.h, ..)`. `SLOAD`/`SSTORE` map `StorageError::NoWitness`/`BadWitness` to the same-named halts. `LOGn` copies topics, ignores data beyond charging its gas. `RETURN`/`REVERT` copy at most `MAX_RETURN_BYTES` (`OutOfBounds` if longer). `PUSHn` past the end of code pads with zeros (EVM semantics). `SWAPn`/`DUPn` index from the top. `PC` pushes the opcode's own offset. `GAS` pushes the remaining gas *after* charging its own 2. `MSIZE` pushes `msize`. `CODECOPY` pads with zero past the code's end. `RETURNDATASIZE` pushes 0; `RETURNDATACOPY` traps unless the size is zero (then it is a no-op charging 3).

Opcode table for the trap set: every byte not in the supported list above traps with `Halt::Trap(op)`, with the sole exception of `0xfe` (`Invalid`).

```rust
/// Reads the input vector through a `read_input(idx) -> u32` closure so the same code runs on the host (over a slice) and the guest (over the syscall).
pub struct InputCursor<F: FnMut(u32) -> u32> { read: F, pos: u32 }
impl<F: FnMut(u32) -> u32> InputCursor<F> {
    pub fn new(read: F) -> Self; pub fn word(&mut self) -> u32; pub fn u256(&mut self) -> U256;     // 8 words, limb 0 first
    pub fn bytes(&mut self, out: &mut [u8]) -> usize;   // n = word(); then ceil(n/4) words unpacked LE into out[..n]; returns n; n > out.len() → panics (the guest's panic handler halts with slot 7 = 0xdead_beef)
}
/// Everything a run needs, decoded from the input layout in the Global Constraints. Static buffers, no allocation.
pub struct CallInput { pub code: [u8; MAX_CODE_BYTES], pub code_len: usize, pub calldata: [u8; MAX_CALLDATA_BYTES], pub calldata_len: usize, pub env: Env, pub pre_root: [u32; 8], pub storage: StorageTree }
pub fn decode_input<F: FnMut(u32) -> u32>(read: F) -> CallInput;
/// out[0] = status, out[1..8] = words 0..6 of dhash(EVM_OUT, codehash ‖ pre_root ‖ post_root ‖ return_hash ‖ logs_hash).
pub fn public_output<H: Host>(h: &mut H, code: &[u8], pre_root: &[u32; 8], post_root: &[u32; 8], o: &Outcome) -> [u32; 8];
pub fn logs_hash<H: Host>(h: &mut H, o: &Outcome) -> [u8; 32];      // keccak256(be32(n_logs) ‖ per log: be32(n_topics) ‖ topics as 32 BE bytes each)
pub fn hash_words(h: &[u8; 32]) -> [u32; 8];                        // word[i] = LE(bytes[4i..4i+4])
/// The whole guest: decode, run, produce the 8 output words.
pub fn run_call<H: Host, F: FnMut(u32) -> u32>(h: &mut H, read: F) -> [u32; 8];

// research/src/evm.rs (host)
pub struct EvmCall { pub code: Vec<u8>, pub calldata: Vec<u8>, pub address: U256, pub caller: U256, pub callvalue: U256, pub gas_limit: u64, pub tree: SparseTree, pub touched: Vec<U256> }

    pub fn input_words(&self) -> Vec<u32>;                 // the Global Constraints layout, witnesses for `touched` in order
    pub fn expected(&self) -> ([u32; 8] /*outputs*/, Outcome, SparseTree /*post tree*/);   // runs evm-core natively over HostRef and applies the same stores to a clone of `tree`
```

```solidity
    event Approval(address indexed owner, address indexed spender, uint256 value);
    function totalSupply() external view returns (uint256) { return _totalSupply; }
    function balanceOf(address a) external view returns (uint256) { return _balances[a]; }
    function transfer(address to, uint256 amount) external returns (bool) { _transfer(msg.sender, to, amount); return true; }
    function allowance(address o, address s) external view returns (uint256) { return _allowances[o][s]; }
    function approve(address s, uint256 amount) external returns (bool) { _allowances[msg.sender][s] = amount; emit Approval(msg.sender, s, amount); return true; }
    function transferFrom(address from, address to, uint256 amount) external returns (bool) {
        uint256 a = _allowances[from][msg.sender]; require(a >= amount, "ERC20: insufficient allowance");
        _allowances[from][msg.sender] = a - amount; _transfer(from, to, amount); return true;
    }
    function _transfer(address from, address to, uint256 amount) internal {
        require(to != address(0), "ERC20: transfer to the zero address");
        uint256 b = _balances[from]; require(b >= amount, "ERC20: transfer amount exceeds balance");
        _balances[from] = b - amount; _balances[to] += amount; emit Transfer(from, to, amount);
    }
}
```

```rust
/// M4.3 exit test: an ERC-20 transfer proves and verifies under R_exec; the public output binds the state-root transition.
#[test]
fn compiled_evm_erc20_transfer_proves_and_verifies() {
    use rand_zkvm::evm::{erc20_transfer, ALICE, BOB};
    let m = Machine::new(FriProfile::Test);
    let p = guests::compiled::evm();
    let call = erc20_transfer(ALICE, BOB, U256::from_u32(250), &[(ALICE, U256::from_u32(1000))]);
    let inputs = call.input_words();
    let (want, outcome, post) = call.expected();
    assert_eq!(outcome.status(), 1, "the native run must succeed before proving");
    assert_ne!(post.root(), call.tree.root());
    let exec = run(&p, &inputs, Tier(16).max_cycles()).unwrap();
    assert_eq!(exec.outputs, want, "the guest's outputs disagree with the native run");
    let (proof, _) = m.prove_salted(&p, &inputs, [9, 10, 11, 12], None).unwrap();
    eprintln!("evm erc20 transfer: {} program words, {} input words, {} cycles, {} poseidon2 permutations, {} keccak permutations, tier {}, keccak_log_height {}, proof {} bytes",
        p.words.len(), inputs.len(), exec.cycles(), exec.events.iter().filter(|e| e.hash_row.is_some()).count(), exec.events.iter().filter(|e| e.keccak_row.is_some()).count(), proof.tier.0, proof.keccak_log_height, proof.to_bytes().len());
    m.verify(&p.digest(), &proof).unwrap();
    assert!(proof.tier.0 <= 16, "M4.3 requires tier ≤ 16");
    // the post-tree the host derived agrees with what the guest bound: recompute the digest from the host's post root
    let mut h = rand_zkvm::evm::HostRef;
    assert_eq!(evm_core::abi::public_output(&mut h, &call.code, &call.tree.root(), &post.root(), &outcome), want);
}
```
