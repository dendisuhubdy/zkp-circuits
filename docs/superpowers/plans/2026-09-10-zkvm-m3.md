# zkVM Milestone 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the machine a native hash. Ship a one-row-per-round Poseidon2 (Goldilocks, width 8) chip driven by a `POSEIDON2` syscall, rebuild `NOTE_COMMIT`/`NULLIFY`/`MERKLE_VERIFY` as guest routines on top of it (retiring `arx.rs`), move the shielded transfer's `cm_in` from a public output to an in-circuit Merkle membership proof against a ledger-maintained commitment tree, and move the program's code hash `hc` in-circuit as a public value so the verifier no longer holds the program.

**Architecture:** A new preprocessed-selector/main-column AIR table (`tables/poseidon2.rs`) proves one Poseidon2 round per row in 32-row blocks, feeding a `POSEIDON2` lookup bus that the CPU table's new "hash rows" (one ecall row + absorb rows + two write rows per syscall) and new "digest rows" (one per four program words, replacing the preprocessed program commitment) both consume; guest-level note primitives and the transfer guest are rebuilt on top of the `POSEIDON2` syscall instead of `arx.rs`, and `Machine::verify` moves from taking `&Program` to taking `&[u32; 8]` (the in-circuit digest `hc`).

**Tech Stack:** Rust 1.98.1, Plonky3 =0.7.0

**Spec:** docs/superpowers/specs/2026-09-10-zkvm-m2-m3-design.md

## Global Constraints

- Every bus message column is constrained on every row kind that sends it (`research/AGENTS.md` invariant 1) — checked explicitly for `POSEIDON2`, the new `MEMORY` hash-lane sends, and the digest-row `PROGRAM`/`POSEIDON2` sends in every task below.
- A bus count is forced to zero wherever its message columns are unconstrained (`research/AGENTS.md` invariant 2) — the Poseidon2 chip's `MULT` and the cpu table's hash-lane `Count`s each get an explicit zeroing constraint, not an implicit one.
- The emulator (`research/src/emulator.rs`) is the reference semantics: if the AIR and the emulator disagree, the AIR is wrong; every new AIR construct here (hash rows, digest rows, the decoder) has an emulator counterpart written first.
- Cheating tests use `rejects()` (`research/tests/cheating.rs`): only a constraint-checker panic (`"constraints not satisfied on row"`) or a `VerifyError` counts as a rejection.
- Docs (`README.md`, `docs/01`, `02`, `03`, `05`, `06`) carry measured numbers (cycle counts, permutation counts, tier, column widths); re-measure and update them in the commit that changes the thing they describe.
- Commit style `research: <area> — <what>`, one logical change per commit (`git log` in `research/`).
- The Poseidon2 chip is Goldilocks width 8, `Perm::new_from_rng_128(&mut StdRng::seed_from_u64(PERM_SEED))` (unchanged from `machine.rs`), giving 4 initial full rounds + 22 partial rounds + 4 terminal full rounds (`GOLDILOCKS_POSEIDON2_HALF_FULL_ROUNDS = 4`, `GOLDILOCKS_POSEIDON2_PARTIAL_ROUNDS_8 = 22`, S-box degree `GOLDILOCKS_S_BOX_DEGREE = 7`); one row per round, 32-row aligned blocks (30 round rows + 2 idle rows), S-box proved through degree-3 `X3`/`X7` intermediate columns (`X3 = (S+RC)^3`, `X7 = X3·X3·(S+RC)`, so `X7 = (S+RC)^7`), the `POSEIDON2` bus keyed `[IN0..7, OUT0..7]` gated by `MULT`.
- `SYS_POSEIDON2 = 3`: `a7 = 3`, `a0 = ptr` (a **word address**, i.e. already divided by 4 — the RAM space is word-addressed everywhere else in this table, e.g. `cpu::MEM_ADDR`, so the syscall ABI matches that convention rather than introducing a byte-address-to-word-address division inside the hash dispatch; see Self-review decisions), `a1 = n` (word count, `0 ≤ n ≤ 4096`); each absorbed 32-bit machine word is one Goldilocks field element directly (no packing on input), the 4-element digest is written back as 8 machine words, `lo`/`hi` of each canonical `u64` element.
- Hash rows (ecall + absorb + write-back) and digest rows count as cycles for tier selection (`Execution::cycles()` counts every `CycleEvent`, and the emulator now emits one `CycleEvent` per hash row, not one per instruction).
- `NOTE_COMMIT`, `NULLIFY`, `MERKLE_VERIFY` are **guest library routines** built from `SYS_POSEIDON2` — no new syscall numbers — with domain tags `CM_DOMAIN`, `NF_DOMAIN`, `NODE_DOMAIN`, `HC_DOMAIN` as the first absorbed word of their respective calls.
- The program table stops being preprocessed: `(PC, WORD, FIELDS[18], VALID)` becomes a **main** trace column set, with an in-circuit decoder proving `FIELDS = decode(WORD)`; the `PROGRAM` bus contract (`(pc, 18 fields)`, `LookupBus`, cpu looks up / program provides) is unchanged.
- `pv::HC0..HC7` are eight new public values (the in-circuit digest); `Machine::verify(hc: &[u32; 8], proof: &Proof)` replaces `Machine::verify(program: &Program, proof: &Proof)` and checks `proof.public_values[HC0..HC8] == hc` in addition to the existing tier/entry-point checks; it takes no `Program`.
- New columns in `cpu.rs` are defined relative to a named constant `WIDTH_AFTER_M2` (the actual cpu-table width once Milestone 2's tasks — sub-word loads/stores, the M extension — have landed; the M2 plan and its implementer fix this number, this plan never hard-codes it).
- Maximum supported AIR constraint degree under the current FRI config is **9**: `build_config`/`generic_config` (`machine.rs`) fix `log_blowup = 3`, and `p3-uni-stark-0.7.0/src/security.rs` asserts `air_max_constraint_degree <= (1 << fri.log_blowup) + 1 = 9`. Every new constraint in this plan is degree ≤ 5 (see M3.1's degree note), well inside that budget — no FRI parameter change is needed for M3.

Note on the `Poseidon2Event`/`HashEvent` naming: M3.1's trace builder consumes whatever event type the emulator produces (defined in M3.2, since only the syscall emits real permutation calls). M3.1 lands the chip and its own unit test harness (which builds `Poseidon2Event`s directly, bypassing the emulator) so the AIR and trace builder can be tested and reviewed before M3.2's syscall plumbing exists; M3.2 then wires `HashEvent` (emulator-level) into the same `poseidon2_trace` builder.

### Degree note

Each full-round row's S-box is split into two selector-gated families instead of one branch that would multiplex `S` and `mds_light(S)` inline (which would push the degree to 6–7 for no benefit):

- `IS_FIRST` (row 0 only): `pre_i = mds_light(S)_i + RC_i` — the initial linear layer applies here, before this round's constants, matching Plonky3's `external_initial_permute_state`.
- `IS_FULL − IS_FIRST` (the other 7 full-round rows): `pre_i = S_i + RC_i`.

Both are preprocessed selectors (booleans, degree 1), `mds_light(S)` and `S` are degree-1 combinations of main columns, so `pre_i` is degree 1 in each branch and `X3_i = pre_i^3` is degree 3, gated to degree 4 by the selector. `X7_i = X3_i · X3_i · pre_i` (all three factors plain degree-1 columns/expressions) is degree 3, gated to degree 4. The round-output constraint `S_next = mds_light(X7)` (full) or `S_next = internal_matmul(X7)` (partial) is degree 1 in `X7`, gated to degree 2. Maximum constraint degree in this chip is **4**.

  ```rust
  use p3_field::PrimeCharacteristicRing;
  use p3_goldilocks::MATRIX_DIAG_8_GOLDILOCKS;
  use p3_field::PrimeField64;

  fn mat4<E: Clone + PrimeCharacteristicRing>(x: &mut [E]) {
      let t01 = x[0].clone() + x[1].clone();
      let t23 = x[2].clone() + x[3].clone();
      let t0123 = t01.clone() + t23.clone();
      let t01123 = t0123.clone() + x[1].clone();
      let t01233 = t0123 + x[3].clone();
      let (x0, x2) = (x[0].clone(), x[2].clone());
      x[3] = t01233.clone() + x0.double();
      x[1] = t01123.clone() + x2.double();
      x[0] = t01123 + t01;
      x[2] = t01233 + t23;
  }

  /// Same operation order as `p3_poseidon2::external::mds_light_permutation` for WIDTH = 8
  /// and the CUDA reference `rand-zkvm-cuda/src/device/poseidon2.rs::mds_light`.
  fn mds_light<E: Clone + PrimeCharacteristicRing>(s: [E; 8]) -> [E; 8] {
      let mut s = s;
      { let mut lo = [s[0].clone(), s[1].clone(), s[2].clone(), s[3].clone()]; mat4(&mut lo); s[0..4].clone_from_slice(&lo); }
      { let mut hi = [s[4].clone(), s[5].clone(), s[6].clone(), s[7].clone()]; mat4(&mut hi); s[4..8].clone_from_slice(&hi); }
      let sums: [E; 4] = core::array::from_fn(|k| s[k].clone() + s[k + 4].clone());
      for i in 0..8 { s[i] = s[i].clone() + sums[i % 4].clone(); }
      s
  }

  /// diag = [-2, 1, 2, 1/2, 3, -1/2, -3, -4] (`MATRIX_DIAG_8_GOLDILOCKS`); mirrors
  /// `p3_goldilocks::poseidon2::GenericPoseidon2LinearLayersGoldilocks::internal_linear_layer`
  /// and the CUDA reference's `internal_matmul`.
  fn internal_matmul<E: Clone + PrimeCharacteristicRing>(s: [E; 8]) -> [E; 8] {
      let mut s = s;
      let sum = s.iter().cloned().fold(E::ZERO, |a, b| a + b);
      for i in 0..8 {
          let d = E::from_u64(MATRIX_DIAG_8_GOLDILOCKS[i].as_canonical_u64());
          s[i] = sum.clone() + s[i].clone() * d;
      }
      s
  }

  fn cube<E: Clone + core::ops::Mul<Output = E>>(x: E) -> E { x.clone() * x.clone() * x }
  ```

- [ ] **Step 2 — round-constant/flag preprocessed trace generator.** `Poseidon2Air::preprocessed_trace` builds one `BLOCK`-row period and repeats it `height / BLOCK` times:

  ```rust
  impl<Fld: Field> BaseAir<Fld> for Poseidon2Air {
      fn width(&self) -> usize { col::WIDTH }
      fn preprocessed_width(&self) -> usize { pre::WIDTH }
      fn preprocessed_trace(&self) -> Option<RowMajorMatrix<Fld>> {
          // Height is a property of the tier (see Step 6), not of this AIR; the preprocessed
          // trace is generated at the tier's height by the caller via `with_height`, mirroring
          // how `byte.rs` fixes its own height but `program.rs` takes the program's length —
          // `poseidon2.rs` takes the tier's poseidon2_height explicitly.
          unreachable!("call Poseidon2Air::preprocessed_trace_at(height) instead")
      }
  }
  impl Poseidon2Air {
      pub fn preprocessed_trace_at<Fld: Field>(height: usize) -> RowMajorMatrix<Fld> {
          assert_eq!(height % BLOCK, 0, "poseidon2 height must be a multiple of {BLOCK}");
          let perm = crate::machine::permutation(); // reuses PERM_SEED, no new constants
          let rc = perm.constants(); // see below: extracted once, cached in a OnceLock in this module
          let mut v = Fld::zero_vec(height * pre::WIDTH);
          for block in 0..height / BLOCK {
              for r in 0..BLOCK {
                  let row = &mut v[(block * BLOCK + r) * pre::WIDTH..(block * BLOCK + r + 1) * pre::WIDTH];
                  if r < HALF_FULL_ROUNDS {
                      row[pre::IS_FULL] = Fld::ONE;
                      for i in 0..8 { row[pre::RC0 + i] = Fld::from_u64(rc.initial[r][i]); }
                  } else if r < HALF_FULL_ROUNDS + PARTIAL_ROUNDS {
                      row[pre::IS_PARTIAL] = Fld::ONE;
                      row[pre::RC0] = Fld::from_u64(rc.internal[r - HALF_FULL_ROUNDS]);
                  } else if r < ROUND_ROWS {
                      row[pre::IS_FULL] = Fld::ONE;
                      let k = r - HALF_FULL_ROUNDS - PARTIAL_ROUNDS;
                      for i in 0..8 { row[pre::RC0 + i] = Fld::from_u64(rc.terminal[k][i]); }
                  } else {
                      row[pre::IS_IDLE] = Fld::ONE;
                  }
                  if r == 0 { row[pre::IS_FIRST] = Fld::ONE; }
                  if r == ROUND_ROWS - 1 { row[pre::IS_LAST] = Fld::ONE; }
              }
          }
          RowMajorMatrix::new(v, pre::WIDTH)
      }
  }
  ```

- [ ] **Step 3 — the AIR.** Full `eval`:

  ```rust
  impl<AB: AirBuilder + InteractionBuilder> Air<AB> for Poseidon2Air
  where AB::F: Field {
      fn eval(&self, b: &mut AB) {
          let p = b.preprocessed().clone();
          let m = b.main();
          let pcur = |i: usize| -> AB::Expr { p.current(i).unwrap().into() };
          let pnext = |i: usize| -> AB::Expr { p.next(i).unwrap().into() };
          let v = |i: usize| -> AB::Expr { m.current(i).unwrap().into() };
          let n = |i: usize| -> AB::Expr { m.next(i).unwrap().into() };
          let one = AB::Expr::ONE;

          let (is_full, is_partial, is_first, is_last, is_idle) =
              (pcur(pre::IS_FULL), pcur(pre::IS_PARTIAL), pcur(pre::IS_FIRST), pcur(pre::IS_LAST), pcur(pre::IS_IDLE));
          b.assert_eq(is_full.clone() + is_partial.clone() + is_idle.clone(), one.clone());

          let is_real = v(col::IS_REAL);
          b.assert_bool(is_real.clone());

          let s: [AB::Expr; 8] = core::array::from_fn(|i| v(col::S0 + i));
          let x3: [AB::Expr; 8] = core::array::from_fn(|i| v(col::X3_0 + i));
          let x7: [AB::Expr; 8] = core::array::from_fn(|i| v(col::X7_0 + i));
          let inp: [AB::Expr; 8] = core::array::from_fn(|i| v(col::IN0 + i));
          let rc: [AB::Expr; 8] = core::array::from_fn(|i| pcur(pre::RC0 + i));

          // Block invariants: IN and IS_REAL persist within a block (reset only when the next
          // row starts a new block, i.e. `pnext(IS_FIRST) == 1`); padding blocks are a suffix.
          {
              let is_first_n = pnext(pre::IS_FIRST);
              let same_block = one.clone() - is_first_n.clone();
              let mut t = b.when_transition();
              for i in 0..8 { t.assert_zero(same_block.clone() * (n(col::IN0 + i) - inp[i].clone())); }
              t.assert_zero(same_block * (n(col::IS_REAL) - is_real.clone()));
              t.assert_zero((one.clone() - is_real.clone()) * n(col::IS_REAL) * is_first_n);
          }
          // Row 0: IN is exactly the raw absorbed state.
          for i in 0..8 { b.assert_zero(is_first.clone() * (inp[i].clone() - s[i].clone())); }

          // Full rounds: the S-box input is `S+RC` everywhere except row 0, where the initial
          // MDS-light layer is applied first (Plonky3's `external_initial_permute_state`).
          let is_full_not_first = is_full.clone() - is_first.clone();
          let ms = mds_light(s.clone());
          for i in 0..8 {
              let pre_first = ms[i].clone() + rc[i].clone();
              b.assert_zero(is_first.clone() * (x3[i].clone() - cube(pre_first.clone())));
              b.assert_zero(is_first.clone() * (x7[i].clone() - x3[i].clone() * x3[i].clone() * pre_first));
              let pre_rest = s[i].clone() + rc[i].clone();
              b.assert_zero(is_full_not_first.clone() * (x3[i].clone() - cube(pre_rest.clone())));
              b.assert_zero(is_full_not_first.clone() * (x7[i].clone() - x3[i].clone() * x3[i].clone() * pre_rest));
          }
          let full_out = mds_light(x7.clone());
          for i in 0..8 { b.assert_zero(is_full.clone() * (n(col::S0 + i) - full_out[i].clone())); }

          // Partial rounds: S-box only on lane 0; other lanes pass X7 = S through unchanged.
          let pre0 = s[0].clone() + rc[0].clone();
          b.assert_zero(is_partial.clone() * (x3[0].clone() - cube(pre0.clone())));
          b.assert_zero(is_partial.clone() * (x7[0].clone() - x3[0].clone() * x3[0].clone() * pre0));
          for i in 1..8 { b.assert_zero(is_partial.clone() * (x7[i].clone() - s[i].clone())); }
          let partial_out = internal_matmul(x7.clone());
          for i in 0..8 { b.assert_zero(is_partial.clone() * (n(col::S0 + i) - partial_out[i].clone())); }

          // Idle rows: nothing else is constrained; MULT is forced to zero below regardless.

          // Bus: on the last round row of a real block, provide [IN, next-S] with count MULT.
          let mult = v(col::MULT);
          b.assert_zero(mult.clone() * (one.clone() - is_last.clone()));
          b.assert_zero(mult.clone() * (one.clone() - is_real));
          let out: [AB::Expr; 8] = core::array::from_fn(|i| n(col::S0 + i));
          let msg: Vec<AB::Expr> = inp.into_iter().chain(out).collect();
          bus::POSEIDON2.table_entry(b, msg, mult);
      }
  ```

  ```rust
  pub fn poseidon2_trace(events: &[Poseidon2Event], height: usize) -> RowMajorMatrix<F> {
      assert!(events.len() * BLOCK <= height, "poseidon2 table needs {} rows for {} events, height {height}", events.len() * BLOCK, events.len());
      let rc = round_constants();

      for (e, ev) in events.iter().enumerate() {
          let base = e * BLOCK;

              for i in 0..8 { row[col::IN0 + i] = ev.input[i]; }
              for i in 0..8 { row[col::S0 + i] = s[i]; }
              if r < ROUND_ROWS {
                  let (pre, is_full) = if r < HALF_FULL_ROUNDS {
                      (if r == 0 { mds_light(s) } else { s }, true)
                  } else if r < HALF_FULL_ROUNDS + PARTIAL_ROUNDS {
                      (s, false)
                  } else {
                      (s, true)
                  };
                  if is_full {
                      let rc_row = round_constant_row(&rc, r);
                      let mut x7 = [F::ZERO; 8];
                      for i in 0..8 {
                          let x3 = (pre[i] + rc_row[i]).cube_via(|x| x * x * x); // (pre+rc)^3
                          row[col::X3_0 + i] = x3;
                          x7[i] = x3 * x3 * (pre[i] + rc_row[i]);
                          row[col::X7_0 + i] = x7[i];
                      }
                      s = mds_light(x7);
                  } else {
                      let rc0 = rc.internal[r - HALF_FULL_ROUNDS];
                      let x3_0 = (s[0] + rc0) * (s[0] + rc0) * (s[0] + rc0);
                      row[col::X3_0] = x3_0;
                      let mut x7 = s;
                      x7[0] = x3_0 * x3_0 * (s[0] + rc0);
                      for i in 0..8 { row[col::X7_0 + i] = x7[i]; }
                      s = internal_matmul(x7);
                  }
              }
              // r == ROUND_ROWS..BLOCK: idle rows, S/X3/X7 already zero from `zero_vec`.
          }
          debug_assert_eq!(s, ev.output, "poseidon2_trace: recomputed output disagrees with the event");
          v[(base + ROUND_ROWS - 1) * col::WIDTH + col::MULT] = F::ONE;
      }
      RowMajorMatrix::new(v, col::WIDTH)
  }
  ```

- [ ] **Step 1 — `SYS_POSEIDON2` and `HashRow`/`HashEvent` types; emulator dispatch.** In `emulator.rs::execute`, the `Instr::Ecall` match arm's `SYS_POSEIDON2` case does not return a single `Syscall` value the way `Halt`/`WriteOutput`/`ReadInput` do; instead it computes the whole multi-row sequence up front and pushes several `CycleEvent`s (sharing `pc`, incrementing `clk`), then `continue`s the outer loop without falling through to the single-event push at the bottom:

- [ ] **Step 2 — `src/hash.rs`: the host-side Poseidon2 sponge reference.** New module (also used by M3.3):

  ```rust
  //! The Poseidon2 sponge exactly as the POSEIDON2 syscall/chip compute it, for host-side use
  //! (guest wrapper generation, ledger/tree code, and the emulator's own reference use above).
  use crate::machine::{permutation, Val};
  use p3_field::{PrimeCharacteristicRing, PrimeField64};
  use p3_symmetric::{CryptographicHasher, CryptographicPermutation, PaddingFreeSponge};

  /// One raw width-8 permutation, `[u32;8]` in, `[u32;8]` out, each word one field element —
  /// exactly the message the POSEIDON2 chip's bus entry carries.
  pub fn permute_words(state: [u32; 8]) -> [u32; 8] {
      let mut s: [Val; 8] = state.map(Val::from_u32);
      permutation().permute_mut(&mut s);
      s.map(|x| x.as_canonical_u64() as u32) // NOTE: truncates; only valid pre-digest-split — see split below
  }

  /// Splits 4 canonical Goldilocks field-element digest lanes into 8 lo/hi machine words.
  pub fn split_digest(elems: [Val; 4]) -> [u32; 8] {
      let mut out = [0u32; 8];
      for (i, e) in elems.iter().enumerate() {
          let v = e.as_canonical_u64();
          out[2 * i] = v as u32;
          out[2 * i + 1] = (v >> 32) as u32;
      }
      out
  }

  /// The sponge the POSEIDON2 syscall computes over `msg` (each element already a small u32,
  /// absorbed as a field element directly), returning the 8 lo/hi digest words.
  pub fn sponge_hash(msg: &[u32]) -> [u32; 8] {
      let sponge = PaddingFreeSponge::<_, 8, 4, 4>::new(permutation());
      let elems: Vec<Val> = msg.iter().copied().map(Val::from_u32).collect();
      let digest: [Val; 4] = sponge.hash_iter(elems);
      split_digest(digest)
  }
  ```

  ```rust
      let count = ord_count.clone() * (one.clone() - v(IS_HASH) - v(IS_HASH_OUT)) + v(ACT0 + k) * v(IS_HASH) + v(IS_HASH_OUT);
      bus::MEMORY.send(b, [space, addr, ts(slot), value, is_write], Count::bounded(count, 1));
  }
  ```

  ```rust
  pub fn emit_merkle_verify(a: &mut Assembler, leaf_ptr: i32, path_ptr: i32, index_reg: u32, depth: usize, root_ptr: i32) {
      const NODE_BUF: i32 = SCRATCH; // 17 words, zero-padded to 20 for 5 whole 4-word blocks
      // running = leaf, copied into a scratch cell
      copy_word8(a, leaf_ptr, RUNNING);
      for level in 0..depth {
          // bit = (index >> level) & 1 ; if bit == 0: [running, sibling] else [sibling, running]
          a.push(srli(T4, index_reg, level as u32));
          a.push(andi(T4, T4, 1));
          // ... branch on T4 to pick the order, copy NODE_DOMAIN + left(8) + right(8) into NODE_BUF ...
          a.extend(li(T5, domain::NODE as i32)); a.push(sw(BASE, T5, NODE_BUF));
          // copy left/right words (8 each) per the branch taken
          a.extend(call_poseidon2((HEAP + NODE_BUF) / 4, 17));
          copy_word8(a, NODE_BUF, RUNNING); // digest overwrote NODE_BUF[0..8]
          a.push(addi(path_ptr_reg, path_ptr_reg, 32)); // next sibling (8 words = 32 bytes)
      }
      copy_word8(a, RUNNING, root_ptr);
  }
  ```

  Opcode one-hot decode mirrors `Instr::decode`'s `match op { OP_LUI => .., OP_AUIPC => .., ... }`, reading `op = bits[0..7]` as a 7-bit value and comparing it against each of the nine known opcodes via an equality gadget (the same inverse-column `eq` trick `alu.rs`'s `AluOp::Eq` already uses, one per opcode, or — cheaper — a single is-one-of-nine check via a precomputed selector column per opcode, each pinned by `OP_IS_X * (op - OP_X) = 0` and `Σ OP_IS_X = VALID`, with an unrecognized opcode forcing every `OP_IS_X = 0` hence `VALID = 0`):

  ```rust

  let op: AB::Expr = (0..7).map(|i| bit(i) * AB::Expr::from_u32(1 << i)).sum();
  let f3: AB::Expr = (0..3).map(|i| bit(12 + i) * AB::Expr::from_u32(1 << i)).sum();
  let f7: AB::Expr = (0..7).map(|i| bit(25 + i) * AB::Expr::from_u32(1 << i)).sum();
  let rd: AB::Expr  = (0..5).map(|i| bit(7 + i) * AB::Expr::from_u32(1 << i)).sum();
  let rs1: AB::Expr = (0..5).map(|i| bit(15 + i) * AB::Expr::from_u32(1 << i)).sum();
  let rs2: AB::Expr = (0..5).map(|i| bit(20 + i) * AB::Expr::from_u32(1 << i)).sum();

  // one boolean selector column per opcode (main, not preprocessed — computed by the trace
  // builder from the actual word, constrained here):
  for (sel, code) in OPCODE_SEL.iter().zip(KNOWN_OPCODES) {
      b.assert_bool(v(*sel));
      b.assert_zero(v(*sel) * (op.clone() - AB::Expr::from_u32(code)));

  let opcode_sel_sum: AB::Expr = OPCODE_SEL.iter().map(|s| v(*s)).sum();
  ```

  ```rust
  pub fn verify(&self, hc: &[u32; 8], proof: &Proof) -> Result<(), VerifyError> {
      if proof.public_values.len() != pv::NUM { return Err(VerifyError::PublicValues); }
      if proof.public_values.iter().any(|x| *x >= Val::ORDER_U64) { return Err(VerifyError::PublicValues); }
      for i in 0..8 { if proof.public_values[pv::HC0 + i] != hc[i] as u64 { return Err(VerifyError::PublicValues); } }
      if !TIERS.contains(&proof.tier.0) { return Err(VerifyError::Tier); }
      if proof.public_values[pv::TIER] != proof.tier.0 as u64 { return Err(VerifyError::Tier); }
      if proof.batch.degree_bits != self.log_ext_degrees(proof.tier) { return Err(VerifyError::Tier); }
      let airs = chips(proof.tier); // no longer takes a Program — program.rs is shape-only now
      let pv: Vec<Val> = proof.public_values.iter().map(|x| Val::from_u64(*x)).collect();
      let pvs: Vec<Vec<Val>> = (0..airs.len()).map(|i| if i == 1 { pv.clone() } else { vec![] }).collect();
      let common = self.verifier_key(proof.tier); // single-entry cache, keyed by tier only
      verify_batch(&self.config, &airs, &proof.batch, &pvs, &common).map_err(|e| VerifyError::Batch(format!("{e:?}")))
  }
  ```

  `pc_entry`'s check moves from "must equal `program.base_pc`" to "must equal whatever the proof's own first row claims" — i.e. it is **no longer independently checkable by the verifier** (the verifier does not have `base_pc` from anywhere except the proof itself), so drop the `PC_ENTRY == program.base_pc` check entirely; `PC_ENTRY` becomes a value the verifier simply reads out of the proof (still bound in-circuit to the first cpu row's `PC`, and now *also* bound to `hc` indirectly since `Program::digest()` absorbs `base_pc`, so a mismatched `pc_entry` claim would require a matching-but-different program to produce the same `hc` — a genuine hash collision, not a free forgery).

  `verifier_key`/`code_hash` collapse `Machine`'s cache key from `(program_digest, tier)` to `tier` alone (M2.1's cache becomes a 6-entry, one-per-`TIERS`-value cache, since the preprocessed trace no longer depends on the program at all — only on the tier, via `Poseidon2Air::preprocessed_trace_at(tier.poseidon2_height())` and the two fixed-height M2.3 tables).

### Name/type consistency across tasks

- `Poseidon2Event` (M3.1, hand-built for chip unit tests) and `HashEvent` (M3.2, emulator-produced) are deliberately two names for structurally similar `{input:[u32;8] or [F;8], output:[u32;8] or [F;8]}` data — M3.1 Step 6 and M3.2 Step 1 both note this and require the M3.2 implementer to either unify them into one type or write a trivial `From` conversion; flagged as an open decision below rather than silently picked.

### Decisions made where the spec left the point open

- `POSEIDON2`'s `a0 = ptr` is a **word address** (already divided by 4), not a byte address needing an in-circuit division — matches every other RAM address in this table (`cpu::MEM_ADDR`) and avoids adding a division constraint the spec's own text doesn't mention needing.
- Absorbed sponge input words are each **one raw field element per 32-bit machine word** (no lo/hi packing on input, only on the final digest output) — inferred from `PaddingFreeSponge<Perm,8,4,4>`'s generic-over-`T` element type and the spec's "8-word (256-bit) commitments" framing, which only makes sense if a 256-bit *output* value needs 8 words while a hash's *input* stream is just its raw words.
- `SpendKey` stays 2 words (not widened to `Word8`) since it is arbitrary private randomness with no width requirement in the spec; only derived/public values (`nk, pk, nf, cm`) become 256-bit.
- Poseidon2 chip S-box constraints are split into `IS_FIRST` / `IS_FULL−IS_FIRST` branches instead of an inline `IS_FIRST`-multiplexed expression, to keep the constraint degree at 4 instead of 6–7; the spec's column list (no separate "pre-layer" column) is honored literally, and the row-0 special case is expressed purely through the selector split.
- M3.2's exact hash-row column count lands at **~44**, not the spec's "about 24" estimate, once lane-activity booleans, digest-word range-check limbs, and the `HASH_FIN` selector are accounted for; the spec's number is a rough estimate, not a target, so this plan does not force a smaller (and more constraint-fragile) encoding to match it.
- This plan's own arithmetic for the rewritten `transfer` guest's permutation count (**≈165**, from 32 Merkle levels × 5 permutations/level plus ≈5 non-Merkle hash calls) exceeds the spec's stated "well under tier 12's 128-permutation budget" — M3.3 Step 7 requires measuring the real number and adjusting `Tier::poseidon2_height` or the target tier accordingly, rather than trusting the spec's estimate.
- `Tier::poseidon2_height` is defined as `self.cpu_height()` (same power of two as the cpu table) in M3.1, pending revision in M3.3 Step 7 if the measured `transfer` permutation count needs a poseidon2-specific height decoupled from `cpu_height`.
- Digest rows' `clk` numbering is chosen to **predate** the first instruction row's `clk` (digest rows get `clk = 0..⌈len/4⌉`, the first real instruction starts at `clk = ⌈len/4⌉`) rather than reusing `clk = 0` for both digest and the first instruction, since the existing `CLK` transition constraint (`n(CLK) = v(CLK)+1` on every real-to-real transition) is simplest to keep totally uniform across digest and instruction rows this way.
- `program.rs`'s decoder proves illegal-encoding rejection (`VALID=0`) via the same one-hot-sum-equals-`VALID` pattern for both the top-level opcode and, one level down, `ALUI`/`ALU` funct3/funct7 legality — chosen over a single flat one-hot across all `(opcode, funct3, funct7)` triples because the latter would need hundreds of selector columns for little benefit.
