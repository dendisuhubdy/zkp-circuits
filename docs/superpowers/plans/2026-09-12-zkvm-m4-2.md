# Rand zkVM M4.2 — Keccak-f[1600] chip and the `KECCAK` syscall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a ninth AIR table to `rand_zkvm` (`circuits/research`) that proves Keccak-f[1600] permutations, and a `SYS_KECCAK = 4` syscall (`a0` = word address of a 50-word state, permuted in place) so that a guest computes `keccak256` of a 136-byte block in one permutation and the result matches the host bit for bit — M4.2's exit test.

**Architecture:** The chip follows the approved §3.1 amendment: the proven Plonky3 `keccak-air` layout (state entering the round as 100 16-bit limbs, column parities `C` and `C' = C ⊕ D` as 2×320 bits, the post-θρπ state `A'` as 1,600 bits, the post-χ state `A''` as 100 limbs, lane (0,0)'s 64 bits and 4 post-ι limbs), degree 3, one row per round in a **32-row block** (24 round rows + 8 idle rows) with preprocessed round selectors and round constants, exactly the way `tables/poseidon2.rs` uses a 32-row block. The chip owns its memory traffic: the cpu's ecall row sends `(clk, ptr)` on a two-element `KECCAK` bus, and the chip's block for that permutation provides `(clk, ptr)` once and issues the 50 word reads (`ts = 4·clk`, 2 per row over the 24 round rows plus 2 on the first idle row) and the 50 word writes (`ts = 4·clk + 1`, 7 per idle row) on the existing `MEMORY` permutation bus, so the cpu table gains one selector and no state columns. The table's height is **proof-declared** (`Proof.keccak_log_height`, minimum 5 = one block), so a guest without `KECCAK` pays for one padding block. No public value changes (`pv::NUM` stays 26); the verifier-key cache key gains a fourth component.

**Tech Stack:** Rust 1.98.1 (`cargo +1.98.1 ...` from `research/`), Plonky3 `=0.7.0`; one new dependency, `p3-keccak = "=0.7.0"` (the plain permutation, for the host reference and the equality test; it pulls `tiny-keccak 2.0.2` and declares edition 2024, which 1.98.1 supports). No `p3-keccak-air` (not in the registry).

**Spec:** `docs/superpowers/specs/2026-09-11-zkvm-m4-design.md` §3 as amended by §3.1 (approved 2026-09-12). Also binding: `research/AGENTS.md` (the two bus invariants; `rejects()` discipline; measured numbers in docs; commit style `research: <area> — <what>`), `research/docs/02-tables-and-buses.md` (the layout every table follows), `docs/superpowers/plans/2026-09-11-zkvm-m4-1.md` (format and the way M4.1 added the `input` table: `Chip` variant appended last, `Traces` field, `log_ext_degrees`, proof-declared height, cache key, pinned-degree test).

## Global Constraints

- Every cargo command: `cargo +1.98.1 ...` run from `research/`.
- **Invariant 1** (`AGENTS.md`): every bus message column is constrained on every row kind that sends it. **Invariant 2**: a bus count is forced to zero wherever the message columns are unconstrained. Padding blocks are honest permutations of the all-zero state with every count zero, exactly like `poseidon2_trace`'s padding.
- **Degree cap 8** (`log_blowup = 3`, `is_zk = 1`): every table's measured max constraint degree stays ≤ 8; `tests/tables.rs::alu_max_constraint_degree_is_pinned` grows to 9 entries and pins the keccak table's measured degree (expected 3; any value is written down, not assumed). The cpu table must stay at 8 — the new selector adds only degree-≤2 terms.
- **Chip order**: `Chip::Keccak` is appended **last** in `machine::chips()` (after `Input`), index 8; `Traces::as_slice`/`heights` become `[_; 9]`; `log_ext_degrees` pushes the keccak entry after the input entry.
- **Bus catalogue**: one new `LookupBus`, `bus::KECCAK`, message `[clk, ptr]` (two field elements). Memory traffic uses the existing `bus::MEMORY` (`PermutationCheckBus`, message `[space, addr, ts, value, is_write]`).
- **Block geometry**: `ROUNDS = 24`, `BLOCK = 32`, `IDLE = 8`; `keccak_log_height(n_perms) = max(5, log2_ceil(32 · n_perms))`; the height is `Proof.keccak_log_height: u8`, checked by `verify` to lie in `5..=MAX_KECCAK_LOG_HEIGHT` where `MAX_KECCAK_LOG_HEIGHT = 20`.
- **State encoding**: lane `(x, y)` is `[u64; 25]` index `x + 5y` (the Keccak / `p3_keccak::KeccakF` order); word `w ∈ 0..50` of the 50-word memory image is `lane[w / 2]`'s low (even `w`) or high (odd `w`) 32 bits, little-endian; limb `l ∈ 0..4` of a lane is bits `16l..16l+16`; so word `w` = `limb[2(w%2)] + 2^16 · limb[2(w%2)+1]` of lane `w/2`.
- **Equality contract**: the chip's trace output on any input equals `p3_keccak::KeccakF.permute([u64; 25])` bit for bit; a randomized test compares 1,000 states.
- **`ptr` bound**: on the cpu ecall row, `ptr < 2^30 − 50` via the same limb decomposition and `RANGE8`/`AND4` lookups `HASH_PTR` already uses (`cpu.rs` "CRITICAL 1"), so `ptr + 49` cannot wrap the memory key `space·2^30 + addr`.
- **Docs carry measured numbers**: keccak table width, its degree, the demo/compiled guest's program words / cycles / tier, the proof-size delta of one padding block, and test counts in `README.md`, `AGENTS.md`, `docs/05-roadmap.md`.
- The fullnode is **not** re-vendored by this plan (that is a constraint-set-5 hard fork the fleet operator schedules).

```rust
//! Keccak-f[1600] as the `KECCAK` syscall and chip compute it, for host-side use (the
//! emulator's reference, trace generation, guest-side sponge tests). The chip proves the same
//! permutation round by round (`tables::keccak`); this module has no columns and no AIR.
use p3_symmetric::Permutation;

pub const LANES: usize = 25;
pub const WORDS: usize = 50;
pub const ROUNDS: usize = 24;

/// ι round constants (FIPS 202 Table 2 order).
pub const RC: [u64; 24] = [
    0x0000000000000001, 0x0000000000008082, 0x800000000000808a, 0x8000000080008000,
    0x000000000000808b, 0x0000000080000001, 0x8000000080008081, 0x8000000000008009,
    0x000000000000008a, 0x0000000000000088, 0x0000000080008009, 0x000000008000000a,
    0x000000008000808b, 0x800000000000008b, 0x8000000000008089, 0x8000000000008003,
    0x8000000000008002, 0x8000000000000080, 0x000000000000800a, 0x800000008000000a,
    0x8000000080008081, 0x8000000000008080, 0x0000000080000001, 0x8000000080008008,
];

/// ρ rotation offsets, `ROT[x][y]`.
pub const ROT: [[u32; 5]; 5] = [
    [0, 36, 3, 41, 18],
    [1, 44, 10, 45, 2],
    [62, 6, 43, 15, 61],
    [28, 55, 25, 21, 56],
    [27, 20, 39, 8, 14],
];

pub fn keccak_f(state: &mut [u64; 25]) {
    p3_keccak::KeccakF.permute_mut(state);
}

pub fn state_to_words(s: &[u64; 25]) -> [u32; 50] {
    std::array::from_fn(|w| if w % 2 == 0 { s[w / 2] as u32 } else { (s[w / 2] >> 32) as u32 })
}

pub fn words_to_state(w: &[u32; 50]) -> [u64; 25] {
    std::array::from_fn(|i| w[2 * i] as u64 | ((w[2 * i + 1] as u64) << 32))
}

/// Keccak-256 (the Ethereum variant: `0x01` domain padding, rate 136).
pub fn keccak256(msg: &[u8]) -> [u8; 32] {
    const RATE: usize = 136;
    let mut state = [0u64; 25];
    let mut padded = msg.to_vec();
    padded.push(0x01);
    while padded.len() % RATE != 0 { padded.push(0); }
    let last = padded.len() - 1;
    padded[last] |= 0x80;
    for block in padded.chunks(RATE) {
        for (i, lane) in block.chunks(8).enumerate() {
            state[i] ^= u64::from_le_bytes(lane.try_into().unwrap());
        }
        keccak_f(&mut state);
    }
    let mut out = [0u8; 32];
    for (i, chunk) in out.chunks_mut(8).enumerate() {
        chunk.copy_from_slice(&state[i].to_le_bytes());
    }
    out
}
```

```rust
const SYS_KECCAK: u32 = 4;

/// `ptr`: a 4-byte-aligned pointer to 50 words (200 bytes) permuted in place. The syscall takes a
/// **word** address in `a0`, so this divides the byte pointer by 4 (the same convention as
/// `poseidon2`, fixed in M4.2).
#[inline(always)]
pub fn keccak(ptr: *mut u32) {
    debug_assert!((ptr as u32) % 4 == 0);
    unsafe { core::arch::asm!("ecall", in("a7") SYS_KECCAK, in("a0") (ptr as u32) / 4, options(nostack)); }
}

/// Keccak-256 (rate 136, `0x01` padding) over `keccak`. `msg.len() <= 136 - 1` fits one permutation.
pub fn keccak256(msg: &[u8]) -> [u8; 32] {
    let mut state = [0u32; 50];
    let mut block = [0u8; 136];
    let mut off = 0;
    loop {
        let take = core::cmp::min(136, msg.len() - off);
        block.fill(0);
        block[..take].copy_from_slice(&msg[off..off + take]);
        let last = take < 136;
        if last { block[take] ^= 0x01; block[135] ^= 0x80; }
        for i in 0..34 { state[i] ^= u32::from_le_bytes([block[4 * i], block[4 * i + 1], block[4 * i + 2], block[4 * i + 3]]); }
        keccak(state.as_mut_ptr());
        off += take;
        if last { break; }
    }
    let mut out = [0u8; 32];
    for i in 0..8 { out[4 * i..4 * i + 4].copy_from_slice(&state[i].to_le_bytes()); }
    out
}
```

2. First row: `pcur(IS_FIRST) · (A_l − IN_l) = 0` for the 100 limbs.
3. All bit columns boolean on round rows: `assert_bool` on `C`, `CP`, `AP`, `APP00B` (unconditionally — they are zero on idle rows in the trace, and 0 is boolean).
4. `C' = C ⊕ C[x−1] ⊕ rotl(C[x+1], 1)`: for all `x, z`: `CP[x][z] = xor3(C[x][z], C[x−1 mod 5][z], C[x+1 mod 5][z−1 mod 64])` with `xor3(a,b,c) = a + b + c − 2(ab + ac + bc) + 4abc` (degree 3), gated by `is_round = 1 − pcur(IS_IDLE)`.
5. Limbs of `A` are consistent with `A'`, `C`, `C'`: for all `x, y, l`: `A[x,y][l] = Σ_{i<16} 2^i · xor3(AP[x,y][16l+i], C[x][16l+i], CP[x][16l+i])`, gated by `is_round`. (This is also the 16-bit range check on every `A` limb, including the `IN` limbs through rule 2 — a sum of 16 booleans × powers of two is a genuine 16-bit integer in a field larger than 2^16.)
6. Parity: for all `x, z`: `diff = Σ_y AP[x,y][z] − CP[x][z]`; `diff · (diff − 2) · (diff − 4) = 0`, gated by `is_round`. (Together with 4 and 5 this pins `C` as the true parity of `A`.)
7. χ: for all `x, y, l`: `APP[x,y][l] = Σ_{i<16} 2^i · (b(x,y,16l+i) ⊕ (¬b(x+1,y,16l+i) ∧ b(x+2,y,16l+i)))` where `b(x,y,z) = AP[(x+3y)%5, x][(z − ROT[(x+3y)%5][x]) mod 64]` and `p ⊕ (¬q ∧ r) = p + (1−q)r − 2p(1−q)r` (degree 3), gated by `is_round`.
8. ι: `APP[0,0][l] = Σ_i 2^i · APP00B[16l+i]` (binds the bits to the limbs), and `APPP00[l] = Σ_i 2^i · (APP00B[16l+i] ⊕ pcur(RC0 + 16l + i))` where `a ⊕ rc = a + rc − 2·a·rc` (rc is preprocessed, degree 2), gated by `is_round`.
9. Round transition: under `when_transition`, for `is_round` rows: `n(A[x,y][l]) = APP[x,y][l]` for `(x,y) ≠ (0,0)` and `n(A[0,0][l]) = APPP00[l]`. (Row 23's next row is idle row 24, which therefore carries the permutation output in `A`.)

11. `KECCAK` bus provide: `mult · (1 − pcur(IS_LAST_ROUND)) = 0`, `mult · (1 − IS_REAL) = 0`; `bus::KECCAK.table_entry(b, [v(CLK), v(PTR)], mult)`.

```rust
/// M4.2 demo: keccak256 of `msg` (≤ 135 bytes, one permutation) with the sponge in guest code,
/// publishing the 32-byte digest as 8 output words.
pub fn keccak_demo(msg: &[u8]) -> Program {
    const BUF: i32 = 0x1000; // byte address of the 50-word state (word address 0x400)
    assert!(msg.len() <= 135);
    let mut block = [0u8; 136];
    block[..msg.len()].copy_from_slice(msg);
    block[msg.len()] ^= 0x01;
    block[135] ^= 0x80;
    let mut a = Assembler::new();
    for i in 0..34 {
        let w = u32::from_le_bytes(block[4 * i..4 * i + 4].try_into().unwrap());
        a.extend(li(T0, w as i32));
        a.push(sw(ZERO, T0, BUF + 4 * i as i32));
    }
    // words 34..49 are zero by the memory table's initial state
    a.extend(call_keccak(BUF / 4));
    for k in 0..8 {
        a.push(lw(T0, ZERO, BUF + 4 * k as i32));
        a.extend(write_output(k as u32, T0));
    }
    a.extend(halt());
    a.program(0)
}
```

```rust
use guest_sdk::{keccak256, read_input, write_output};

#[no_mangle]
pub extern "C" fn main() {
    // input[0] = byte length n (≤ 135), input[1..] = the message packed 4 bytes per word, LE
    let n = read_input(0) as usize;
    let mut msg = [0u8; 136];
    let mut i = 0;
    while i < n {
        let w = read_input(1 + (i / 4) as u32);
        msg[i] = (w >> (8 * (i % 4))) as u8;
        i += 1;
    }
    let d = keccak256(&msg[..n]);
    let mut k = 0;
    while k < 8 {
        write_output(k as u32, u32::from_le_bytes([d[4 * k], d[4 * k + 1], d[4 * k + 2], d[4 * k + 3]]));
        k += 1;
    }
}
```

```rust
/// M4.2 exit test: keccak256 of a 135-byte message (one rate block) from a compiled guest matches
/// the host in one permutation.
#[test]
fn compiled_keccak256_matches_the_host_in_one_permutation() {
    let m = Machine::new(FriProfile::Test);
    let p = guests::compiled::keccak256();
    let msg: Vec<u8> = (0..135u8).map(|i| i.wrapping_mul(31)).collect();
    let mut inputs = vec![msg.len() as u32];
    for c in msg.chunks(4) { let mut w = [0u8; 4]; w[..c.len()].copy_from_slice(c); inputs.push(u32::from_le_bytes(w)); }
    let exec = run(&p, &inputs, Tier(12).max_cycles()).unwrap();
    let want = keccak::keccak256(&msg);
    for k in 0..8 { assert_eq!(exec.outputs[k], u32::from_le_bytes(want[4 * k..4 * k + 4].try_into().unwrap())); }
    assert_eq!(exec.events.iter().filter(|e| e.keccak_row.is_some()).count(), 1);
    let (proof, _) = m.prove_salted(&p, &inputs, [5, 6, 7, 8], None).unwrap();
    eprintln!("keccak256 guest: {} words, {} cycles, tier {}, keccak_log_height {}, proof {} bytes", p.words.len(), exec.cycles(), proof.tier.0, proof.keccak_log_height, proof.to_bytes().len());
    m.verify(&p.digest(), &proof).unwrap();
}
```
